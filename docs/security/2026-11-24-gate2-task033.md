## Findings

**G2T033-01 [Low] Long-number rule bypassed with Thai digits. FIXED.**
- `g1._DIGITS` was `[0-9]{15,}`. Thai digits ๐–๙ pass the charset rule and are not folded by NFKC.
- So a 15-digit Thai-digit run (an ID or phone number) passed `content_bad` and routed `routine`. Probe result: `content_bad(...)` returned False and `hq_reason` returned None.
- Fix: `_DIGITS = re.compile(r"\d{15,}")`, which covers every Unicode decimal digit.
- Test: one new parametrize case in `test_content_refused`.

**G2T033-02 [Medium] G1 keyword routing bypassed with inflections. REQUIRED (backend, test-first).**
- `_KW` ends with `(?![a-z0-9])`, so a listed word followed by any letter is not a hit.
- Probe: `hq_reason("method", "always check the {w} before starting work")` returns None for each of: admins, approvals, approving, bypassing, ignoring, ignored, overriding, refunds, invoices, contracts, budgets, discounts, deleting, deleted, escalated.
- Impact: these lessons go to the AI head instead of humans. This is the same class as G033-02/03.
- Remediation:
  - Allow an optional suffix `(?:s|es|d|ed|ing|er|ers)?` before the trailing lookahead.
  - Add stems for the irregular forms: `approv`, `overrid`, `ignor`, `delet`, `escalat`, `authori`.
  - Over-matching routes to HQ, so it fails safe.
  - Add AT-2 cases for each form above.

**G2T033-03 [Low] Classifier money rule and understated value. REQUIRED (ai-prompt, prompt only).**
- What still holds:
  - `Router.route` runs every fixed rule (kind, access, `value_thb >= threshold`, cross_dept, no_dept, no_head, requester_is_head, ai_disabled) before the classifier.
  - The router treats any output other than an exact `routine` as major (`out != "routine"` after `strip()`).
  - `decide_as_head` still requires `value_thb IS NOT NULL AND value_thb < threshold`.
  - `value_thb` is required by `cards.CARD_REQUIRED`.
  - No injection path to `dept` is opened.
- The gap: the old line "spending is major" was a second check against a self-declared `value_thb`. Now a card with a low `value_thb` and text such as "small purchase" reaches the AI head. The prompt does not say that "stated value" means the `value_thb` field.
- Remediation, in `prompts/_system/approval-classifier.md`:
  - Add: "The stated value is the `value_thb` field. A purchase with `value_thb` 0, or text that names a larger amount than `value_thb`, is `major`."
  - Add one example of each.

**G2T033-04 [Low] Task embed falls back to the TASKS channel. Owner decision, not blocking.**
- `TaskService` sends the task to `tasks_channel_id` when `visible_to` is false.
- A task ordered in a restricted channel (the HQ lounge) is then reposted, with its title, in the wider TASKS channel.
- A `get_channel` cache miss also returns False, which widens visibility.
- Remediation: the owner confirms that TASKS is acceptable for HQ-origin tasks; otherwise refuse with a clear error.

**G2T033-05 [Low] `add_dept` can leave a department half-created.**
- The `departments` row commits first. `st.set(channel)` and `_move(head)` run after it, outside that transaction.
- Both are pre-validated, so a failure needs a DB error or a race.
- No test covers this path.
- Remediation: wrap all three steps in one transaction, or on failure refuse and report which step failed.

**Note (Info):** `build_system` drops an oversized overlay without the `growth.overlay_dropped` log that G033-04 asks for. The path is unreachable within the tested bounds.

## Areas with no finding

- **Authorization:** every growth command goes through `_setting_gate` (exact settings channel and a fresh approver). Replies go through `_say` (masked, ephemeral).
- **Escalation:**
  - `/hire` can only use models from `file_models()` and only the fixed `HIRED_TOOLS`.
  - `resolve_dept` refuses HQ-only departments.
  - `_target` protects the intake persona, the default persona and HQ personas.
  - A head must have its own bot (`is_disabled` now includes `pid not in app.bots`).
- **Lesson forgery:** `payload.lesson` is set only by `LessonService`. `_lesson_aware` routes on it, and the proposer must match.
- **Prompt:** overlays are excluded from `approval_review` runs (`engine` `req.trigger != "approval_review"`). They are wrapped untrusted and masked, and `wrapper.md` declares them advisory. Lessons cannot contain `<`, so `_escape` growth is zero.
- **DoS:**
  - `lessons_per_day` is limited to 0..50, with at most 3 items per task.
  - The cap and budget are checked before the LLM call.
  - Each task fires the hook once, because `set_task` refuses closed tasks.
  - The overlay is limited to 500..6000 chars.

**G2T033-02, G1 inflections. CLOSED.**
- `_KW` now uses `_SUFFIX` = `(?:s|es|d|ed|ing|er|ers|ion|ions|ment|ments)?`. For keywords ending in a single-word `e`, the final `e` becomes optional.
- No new false negative. A property probe ran every `_ASCII` keyword through 9 contexts (bare, in a sentence, possessive, punctuation, parentheses, hyphen, `pre-` prefix, `+s`, `+ing`). Every text the old pattern matched also matches the new one (0 violations). The new pattern is a strict superset because each alternative still matches the bare keyword.
- ReDoS: no nested quantifiers. 8 KB of near-miss input takes under 1 ms.
- Probe of 120 more forms. Still missed before this re-check: overridden, overrode, spent, salaries, monies, transferred, transferring, instructed, unauthorized, unapproved, preapproved, superadmin, sysadmin.
- **Fixed in this re-check:** these were added as literal entries to `_ASCII` in `core/growth/g1.py`, so the `e?` and suffix handling cover their forms too. 14 parametrize cases were added to `test_inflected_keywords_force_hq`, including "api keys". Over-matching routes to HQ, so it fails safe. Plain method lessons still route `None` (`test_plain_method_lesson_still_routine`).
- Still missed (residual, see below): derivational and prefixed forms such as lawful, legally, jailbroken, destruction, externally, disapproved, redeploy, autodeploy, undelete, reupload and noncompliance.

**G2T033-03, classifier money rule. CLOSED.**
- `prompts/_system/approval-classifier.md` now says the amount limit is checked by fixed rules on `value_thb`. `routine` needs `value_thb` above 0 and no text naming a larger amount, a recurring charge or more units.
- It has three examples: value 1,500 with value_thb 1500 is routine; 500/month for 24 months is major; total 3,000 with value_thb 0 is major.
- The router's `out != "routine"` path is unchanged (router.py md5 matches the block above).

**G2T033-04, tasks-channel fallback. ACCEPTED RISK (owner decision 2026-11-24).**
- A task ordered in a restricted channel (the HQ lounge) is reposted, with its title, in TASKS when the assignee cannot see the origin channel.
- A `get_channel` cache miss also takes this path and widens visibility.
- The owner keeps the fallback. Revisit this if HQ-only task titles become sensitive.

**G2T033-05, add_dept partial state. CLOSED.**
- The `departments` transaction commits first. The `try` block (channel set, then `_move`) runs after that `async with` exits.
- Any exception is logged as `growth.dept.add_partial` (code and step only) and re-raised as `GrowthError("dept_partial")`. `growth_commands._ERR["dept_partial"]` maps it to a user message that names `/setting` and `/move`.
- Test: `test_add_dept_late_failure_reports_partial`.
- **Hardened in this re-check:** `step=getattr(e, "code", ...)[:32]` became `str(getattr(...))[:32]`. Without it, an exception with a non-str `code` (such as an int HTTP code) would raise TypeError inside the `except`, and `dept_partial` would never be raised. All project error classes use str codes today, so this is hardening only.

**DEFECT-001, overlay cap read outside the transaction. NO FINDING.**
- `on_decision` and `delete` call `max_chars(settings)` before `db.transaction()`. `rebuild(..., cap=)` is called only from `lessons.py` (3 call sites), never from user input.
- `max_chars` clamps the value to 500..6000 and falls back to 3000 on error.
- A setting change between the read and the transaction affects only the stored history body or the kept set. `prompt_block` re-renders with a fresh cap, and `build_system` still drops anything over `OVERLAY_HARD_MAX_CHARS`.

**REPLY_TIER2_MODEL = google/gemini-3.1-flash-lite. NO FINDING.**
- `prices.TOKEN["gemini-3.1-flash-lite"] = (100_000, 400_000)`. This is non-zero and marked as a placeholder list price.
- An unknown model id is charged the maximum token price, with the `budget.unknown_model` log, so a typo cannot under-count spend.
- Classifier (`router.make_classifier`): budget stop, a missing adapter, a timeout or an exception gives `classifier_unavailable` (HQ). Any output other than an exact `routine` gives `classifier_major`. This is covered by `test_head_and_ai_switches_and_classifier_outcomes`.
- Reply-gate `tier2`: every failure returns None (silent) through the `try/except`. A positive answer must pass `_OUT.fullmatch` and be in `ids`. Bad output, budget stop and rate limit are covered by `test_classifier_bad_output_is_silent` (including trailing text and empty output) and `test_tier2_budget_stop_and_rate`. For adapter exceptions and timeouts the evidence is the code path only; no dedicated test exists (Info).
- The fail-closed behaviour is unchanged.
