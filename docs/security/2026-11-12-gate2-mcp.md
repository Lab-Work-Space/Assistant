## Residual risks (plain words)

1. Docker or kernel bugs can let a hostile image escape. The app user can drive Docker anyway.
2. Tool descriptions sit in every granted department's prompt before any call. A Bot Admin reads them, but a clever wording can still steer a bot.
3. Read-class answers can steer a run. Inside autopilot trees, a steered run's ordinary writes still auto-run.
4. Anyone with database access can still change an active row and also rewrite its `approved_config_sha256` pin to match. A change of `image_id`, `command`, `env`, class or a grant WITHOUT the pin is caught at load and at every call (migration 047); a database owner who recomputes the pin is not, since the pin is a tripwire and not a signature.
5. The static import check cannot see reflection with a computed name. Code review and the dev-job path protection cover it.
6. One stuck container stops all MCP calls until restart. A server whose image was missing at boot stays out until restart.
7. The protocol versions (`2025-11-25`, `2025-06-18`, `2025-03-26`) have not been tried against a real third-party server.
