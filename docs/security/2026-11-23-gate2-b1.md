## Accepted deviations
- **Task-thread bypass of the hourly limit:** the bypass is accepted, but its assumed bound (the turn limit) fails when messages arrive concurrently (probe above). Raised as G2B1-01, Medium.
- **Trailing-name Tier 1 ("…yes:praw"):** no extra risk. A Tier 1 reply gives the same capability as an @mention, which any user in an allowlisted channel already has. The run carries the real author as the human trigger, approvals still fetch the role fresh, and Tier 2 output must fully match `yes:<candidate id>`. Info.
- **Pull-user join as a link button:** it creates no interaction and needs no routing. The URL is built from the configured guild id and an allowlisted channel id (ints only). Info.
- **Streaming NotFound re-post:** see G2B1-02 (Low).
