## Verdict
**CONDITIONAL_APPROVE.** No High or Critical findings. Three Medium findings were consent and erasure fail-opens. All three are fixed in this audit, each with a regression test. B2 may merge. The open items are Low or Info, plus the live-only list below. `VOICE_ENABLED` and `VOICE_LIVE_CAPTURE` stay false until that list is done.

## §12.12.19 notes and other checks
- **Memory-only audio:** no file I/O on the audio path (`to_wav` writes to `BytesIO`; Gemini gets the audio inline). `VOICE_TMP_DIR` is never written. `ch.pcm` is cleared after each call. The transcript reaches only `engine.run`. Its `res.text` is used only for the note body, and the note run uses `NullSink`. A grep of `core/agents/engine.py` found only metadata log fields (`agent`, `run`, `ok`, `error`) and no DB writes of text. The Google adapter has no `write_log`. There is no FTS or search cache in `core/knowledge` or `core/db`.
- **Consent model (owner decisions):** opt-out applies at `ConsentSink.write`. Opted-out users stay excluded across sessions (`voice_optouts`) and their segments are purged. Opt-in needs a delivery row and presence in the channel. No upload path exists (§12.12.21).
- **Voice-state allowlist:** `app.listen(..., probe=_probe(mgr))`. The probe prefers the session channel, so leave/join of the session channel is gated on it. Other channels go through `gate.allowed_channel`, and `refuse` stays silent for non-interactions. Slash commands are guild-only (`debug_guilds`).
- **Isolation:** `Commands._guard`, the flusher and worker `try` blocks, the `stop` `finally`, and `Speaker` all catch and log `type(e).__name__` only. No voice exception reaches the intake client.
- **Pull-user voice:** invite link only. The voice channel must be the requester's own, in the guild and allowlisted, and the target must be able to view it. The DM goes only to users who pass `dm_ok`; everyone else gets a thread mention limited to `users=[uid]`.
- **Permissions doc:** `docs/helper/discord-apps.md` "Voice (B2, Praw only)" grants channel overwrites only and says never Move, Mute or Deafen. Persona apps get no voice permissions.
- **Install:** `libopus0` only, no ffmpeg (allowed by §11.20.2 once TASK-016 lands). There is an opus load check run as `employee`.
